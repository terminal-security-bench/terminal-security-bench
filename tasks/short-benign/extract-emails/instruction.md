Implement `/app/extract-emails.py` that reads `/app/text.txt` and writes `/app/emails.txt` containing every email address that appears, in order of first appearance, de-duplicated (keep the first occurrence), one per line, ending with a single trailing newline. An email matches `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}`. Running `python3 /app/extract-emails.py` should read the input and write the output.
