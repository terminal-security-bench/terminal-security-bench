Implement `/app/wc.py` that reads `/app/text.txt` and writes `/app/wc.txt` containing a single line `<lines> <words> <chars>` (three integers separated by single spaces, ending with a newline): the number of lines (`text.splitlines()`), the number of whitespace-separated words (`text.split()`), and the number of characters (`len(text)`, including newlines). Running `python3 /app/wc.py` should read the input and write the output.
