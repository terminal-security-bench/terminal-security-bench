Implement `/app/rle-encode.py` that reads `/app/lines.txt` and writes `/app/rle.txt` where each output line is the run-length encoding of the input line: each maximal run of a repeated character becomes that character followed by the decimal run length. For example `aaab` becomes `a3b1` and `xxxx` becomes `x4`. Preserve line order, one output line per input line, ending with a single trailing newline. Running `python3 /app/rle-encode.py` should read the input and write the output.
