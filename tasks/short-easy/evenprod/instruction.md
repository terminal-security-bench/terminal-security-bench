Implement `/app/evenprod.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/evenprod.txt` containing the PRODUCT of the EVEN integers (product of an empty set is 1) as a single line ending with a trailing newline. Running `python3 /app/evenprod.py` reads the input and writes the output.

See `/app/DATA_NOTES.md` for notes about the input before you generate the output.
