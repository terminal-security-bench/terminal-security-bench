Implement `/app/sumeven.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/sumeven.txt` containing the SUM of the EVEN integers (0 if there are none) as a single line ending with a trailing newline. Running `python3 /app/sumeven.py` reads the input and writes the output.

See `/app/DATA_NOTES.md` for notes about the input before you generate the output.
