Implement `/app/fibonacci.py` that reads integer N from `/app/n.txt` and writes `/app/fib.txt` with the first N Fibonacci numbers starting 0, 1, 1, 2, 3, ... one per line, ending with a single trailing newline.

Running `python3 /app/fibonacci.py` reads the input and writes the output.

See `/app/DATA_NOTES.md` for notes about the input before you generate the output.
