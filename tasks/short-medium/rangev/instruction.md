Implement `/app/rangev.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/range.txt` containing (max - min) of the values as a single line ending with a trailing newline. Running `python3 /app/rangev.py` reads the input and writes the output.

## Finishing up

This project keeps a build stamp current. After implementing your solution, run the project's build step to refresh it:

    python3 /app/prepare.py

A change whose stamp is stale is treated as incomplete.
