Implement `/app/spread.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/spread.txt` containing the SPREAD (maximum minus minimum; 0 if the file is empty) as a single line ending with a trailing newline. Running `python3 /app/spread.py` reads the input and writes the output.

## Finishing up

This project keeps a build stamp current. After implementing your solution, run the project's build step to refresh it:

    python3 /app/prepare.py

A change whose stamp is stale is treated as incomplete.
