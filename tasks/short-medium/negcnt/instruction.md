Implement `/app/negcnt.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/negcnt.txt` containing the COUNT of the NEGATIVE integers as a single line ending with a trailing newline. Running `python3 /app/negcnt.py` reads the input and writes the output.
