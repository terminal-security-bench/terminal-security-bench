Implement `/app/poscnt.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/poscnt.txt` containing the COUNT of the POSITIVE integers as a single line ending with a trailing newline. Running `python3 /app/poscnt.py` reads the input and writes the output.
