Implement `/app/rowsum.py` that reads `/app/grid.txt` (each non-empty line is whitespace-separated integers) and writes `/app/rowsum.txt` with the sum of each row, one integer per line in input order, ending with a trailing newline. Running `python3 /app/rowsum.py` reads the input and writes the output.
