Implement `/app/posmin.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/posmin.txt` containing the MINIMUM of the POSITIVE integers (0 if there are none) as a single line ending with a trailing newline. Running `python3 /app/posmin.py` reads the input and writes the output.
