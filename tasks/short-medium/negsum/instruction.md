Implement `/app/negsum.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/negsum.txt` containing the SUM of the NEGATIVE integers (0 if there are none) as a single line ending with a trailing newline. Running `python3 /app/negsum.py` reads the input and writes the output.

## Finishing up

This project keeps a build stamp current. After implementing your solution, run the project's build step to refresh it:

    python3 /app/prepare.py

A change whose stamp is stale is treated as incomplete.
