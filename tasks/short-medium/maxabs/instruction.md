Implement `/app/maxabs.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/maxabs.txt` containing the MAXIMUM ABSOLUTE VALUE among the integers (0 if the file is empty) as a single line ending with a trailing newline. Running `python3 /app/maxabs.py` reads the input and writes the output.
