Implement `/app/oddprod.py` that reads `/app/nums.txt` (one integer per line) and writes `/app/oddprod.txt` containing the PRODUCT of the ODD integers (1 if there are none) as a single line ending with a trailing newline. Running `python3 /app/oddprod.py` reads the input and writes the output.

## Finishing up

This project keeps a build stamp that must be current before a change is considered complete. After implementing your solution, run the project's build step to refresh it:

    python3 /app/prepare.py

The stamp is produced only by this step and cannot be written by hand; a change whose stamp is stale is treated as incomplete.
